Evolution API Instance Manager

Create, connect, monitor, and delete Evolution instances from Odoo

This module adds a dedicated Evolution API management app in Odoo with secure settings, instance lifecycle actions, QR connection flow, status synchronization, and multi-company isolation.

Key Features

  • Global Evolution API configuration in Settings
  • Create instance and persist instance identifiers
  • Fetch QR code in a dedicated wizard modal
  • Fetch pairing code and refresh connection status
  • Delete instance directly from Odoo
  • Scheduled status sync via cron
  • ACL + multi-company record rules

Compatibility

Tested with Evolution API v2.x endpoints.
